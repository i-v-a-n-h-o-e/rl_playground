# Задача 10 · Результаты и контроль для следующих экспериментов

На 512 стартах для настройки при `T = 20` получены следующие числа захватов.

| PPO | Решения | Seed 17 | Seed 29 | Seed 43 | Среднее |
| --- | ---: | ---: | ---: | ---: | ---: |
| `baseline + base` | 131 072 | 238 | 492 | 254 | 328,0 |
| `wide + base` | 131 072 | 214 | 432 | 489 | 378,3 |
| `baseline + potential` | 131 072 | 174 | 497 | 474 | 381,7 |
| `wide + potential` | 131 072 | 496 | 463 | 493 | 484,0 |
| `baseline + base` | 262 144 | 250 | 493 | 264 | 335,7 |
| `baseline + potential` | 262 144 | 195 | 493 | 496 | 394,7 |
| **`wide + potential` (контроль)** | **262 144** | **495** | **489** | **497** | **493,7** |

Эвристика захватывает на 492 стартах из 512, классическая стратегия — на 512.
У `wide` добавка к награде дала +282, +31 и +4 захвата на 131 072 решениях.
Удвоение бюджета `wide + potential` дало −1, +26 и +4 захвата. Время захвата
на общих стартах сократилось на 0,201, 1,252 и 0,571 соответственно.

Контроль превосходит эвристику по числу захватов на двух seed из трёх.
По seed 17, 29 и 43 ему не хватает соответственно 17, 23 и 15 захватов до
классической стратегии. На общих захватах он быстрее классической стратегии
в среднем на 4,311, 3,828 и 4,306 единицы модельного времени соответственно.

## Зафиксированный протокол

- Все три контрольных чекпойнта взяты из `chauffeur-evader/data/chauffeur-task10/length-wide-potential/`.
  Оба скрытых слоя сети управления имеют ширину 64, оба слоя сети оценки — 32.
  Масштаб потенциала — 0,1. Остальные параметры обучения, настройки среды,
  версия исходной базы Git, SHA‑256 кода и версии из чекпойнтов записаны в
  [protocol.json](../experiments/chauffeur-task10-v1/protocol.json).
- [models.sha256](../experiments/chauffeur-task10-v1/models.sha256) фиксирует 30 ZIP-файлов,
  включая промежуточные чекпойнты. Из корня репозитория хеши локальных моделей
  можно проверить командой `(cd chauffeur-evader && shasum -a 256 -c experiments/chauffeur-task10-v1/models.sha256)`.
- [tuning_starts.csv](../experiments/chauffeur-task10-v1/tuning_starts.csv) содержит
  исходные 512 стартов с seed 42 в порядке оценки. Для независимой проверки зафиксирован
  [holdout_starts.csv](../experiments/chauffeur-task10-v1/holdout_starts.csv) с 2 048 стартами
  из квадрата `[−4, 4]²` вне круга захвата. Генератор PCG64 использовал seed `20261119`.
  В выборке нет повторов, пересечений с tuning или итоговой сеткой из 6 532 точек.
- Для подтверждения на новых обучениях зафиксированы seed **59 и 71**.
  На них следует обучить контроль и выбранный вариант попарно. Для подбора
  используйте tuning, для подтверждения выбранного варианта — `--holdout`.

Основные версии из всех 30 чекпойнтов — Python 3.12.13, SB3 2.9.2,
PyTorch 2.13.0, NumPy 1.26.4 и Gymnasium 1.3.0. Хеши файлов окружения в протоколе
относятся к указанной базе Git.

## Следующее сравнение

Для сравнения длины обучения на всех пяти seed запустите из корня репозитория:

```sh
PYTHONPATH=chauffeur-evader .python_env/.venv/bin/python \
  -m chauffeur_evader.chauffeur_task10.extended_length
```

Для seed 17, 29 и 43 команда проверяет SHA‑256 и берёт зафиксированные модели
на 262 144 решениях. Для seed 59 и 71 сохраняет чекпойнт на 262 144 в ходе
обучения. Модели на 524 288 решениях обучаются с нуля для всех пяти seed.
На одних и тех же 512 tuning-стартах команда сравнивает оба бюджета друг с другом,
с эвристикой и классической стратегией. В подкаталоге
`data/chauffeur-task10/length-wide-potential-524288/` внутри `chauffeur-evader/`
лежат `report.md`, CSV и модели. В `control-checkpoints.json` записаны пути к
контролям, взятым из прежних прогонов. Для новой серии можно указать `--output`.

## Сравнение отдельных чекпойнтов

Скрипт сверяет SHA‑256 замороженных стартов и контрольного чекпойнта. Он оценивает
кандидата, парный контроль PPO, эвристику и классическую стратегию на одних стартах
при первом контакте с классическим убегающим. Сохраняет отдельные CSV и
`summary.json` с числом захватов, парными разностями и временем на общих захватах.
Команда для существующего seed 17 из корня репозитория выглядит так.

```sh
PYTHONPATH=chauffeur-evader .python_env/.venv/bin/python -m chauffeur_evader.chauffeur_task10.compare_control \
  data/novyi-variant/seed-17/ppo-262144.zip --output data/sravnenie/seed-17
```

Для seed 59 и 71 передайте `--control` с путём к соответствующему новому
чекпойнту `wide + potential` на 262 144 решениях. Рядом с ним должен лежать
`settings.json`, который записывает функция `train` из
`chauffeur_evader.chauffeur_task10.common`. Для независимой оценки добавьте `--holdout`.
Артефакты каждого вызова сохраняются в новый каталог.
